# Telco Customer Churn Analysis Dashboard

## Project Overview
This project analyzes customer churn behavior using Power BI. The dashboard helps identify churn patterns, customer retention drivers, and business insights for a subscription-based telecom company.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV Dataset

## Dataset
Telco Customer Churn Dataset from Kaggle.

## Key Metrics
- Total Customers
- Churn Customers
- Churn Rate
- Average Monthly Charges
- Average Tenure

## Dashboard Features
- KPI Cards
- Churn Distribution Analysis
- Contract-Based Churn Analysis
- Internet Service Analysis
- Tenure Group Analysis
- Interactive Filters/Slicers

## Key Insights
- Month-to-month customers have highest churn.
- Fiber optic users churn more frequently.
- High monthly charges increase churn probability.
- Customers with shorter tenure are more likely to leave.

## Business Recommendations
- Encourage long-term contracts.
- Improve customer onboarding.
- Provide loyalty rewards.
- Optimize pricing strategies.
